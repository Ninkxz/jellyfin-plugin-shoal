| D17 | Both servers must have Shoal (2026-10-16, supersedes D7) | **Plugin-only pairing.** Both sides need Shoal; pairing is by invite only (invite code + safety code). Quick Connect pairing and every "create an account on your Jellyfin" instruction are removed from the UI, wizard, docs and README. No route for LAN-http (LAN only is for testing; real friends use Tailscale or https). The owner confirmed (2026-10-16) that nobody uses Quick Connect, so **legacy QC peers are not supported either**: a peer paired the old way loads, keeps its libraries and titles, is paused and shows "Re-pair by invite" (no anchor, device lock, session-limit or rotation code for it). The anonymous Shoal ping stays and drives the "install Shoal first" check. **Details (2026-10-16):** the pairing wizard has five steps (Address, Check, Invite, Code, Choose); a definitive "no Shoal" answer blocks with the install address https://github.com/Ninkxz/jellyfin-plugin-shoal and a message to copy to the friend, while a throttled or unreadable ping only shows a soft hint; a legacy peer shows "Needs pairing again" and a **Pair again with an invite** button (the old token is signed out on a best effort basis, libraries are kept); D7 is superseded. Design: `docs/DESIGN.md` "Changes in v2.8"; plan: `docs/plans/d17-remove-quick-connect.md`; screens: `docs/ui-spec-pairing-v2.md`. |

Servers that already have Shoal keep their current mode; the page shows a clear one-click "Require sign-in" card with the log result. The log stays available (switch to log only), and the 7 day log result still says what would be blocked. |
